# 新上传教学与词卡完善

基线：cf58b70（开始修改前 main）。不重新生成、不改写、不发布两个旧视频的任何教学或媒体数据。

## 实施及验收

1. 词卡采用既有雾蓝深浅主题设计：标题和底部按钮固定在卡片内，中部独立滚动；发音、关闭 44px 触摸区域，18px 图标不变形。缺失字段隐藏，例句来自所选字幕，显示真实中文。保留复制、收藏、播放原句及词语发音。
2. 难度统一支持高考、专升本、四级、六级、专四、专八、雅思、托福；筛选仅列出实际已发布且审核通过的视频所含难度，不伪造等级，不重标旧视频。生成、校验、编辑与读取共享同一取值集合。
3. 新上传自动执行 540P 转码、字幕、口语翻译、DeepSeek 重点选词、覆盖检查、终检、核心释义与发音准备。四级包含在内；俚语、合格短语与实词保持彩色、连续下划线。不得为了颜色把简单连接词或自由组合包装成高级词。沿用现有发布审核，不新增教学复核要求。
4. 解析队列提供刷新状态和继续失败任务。刷新不新建任务；继续复用同一任务与检查点，提交期间防重复点击，失败反馈持续可见。上传失败留在上传清单，重试跳过成功行、复用已上传原片及任务幂等键。
5. 执行相关契约、Python 和响应式 UI 检查；code-review 分别核对规范与需求。官方迁移验证通过后 Git 发布，HTTPS 核验生产资源；安全隐藏重启本地 Worker 使新提示词生效。不得以静态核验冒充真实手机端到端验收。

## 恢复

代码通过后续恢复提交回滚。新增数据库难度校验兼容原四类；本次不修改旧视频，不做媒体删除。
