## 1. 目标与边界

产品定位：以 Vlog 为内容的英语观看、精听和练习网站。手机首页帮助用户找视频、继续学习；播放页集中呈现视频、字幕与必要学习工具。

本轮汇总最近讨论的手机首页、手机播放器、字幕显示、固定操作栏、学习模式及视频连续播放要求。此前账号、VIP、邀请码、上传与删除等系统作为回归保护项，不借此次 UI 迭代重新设计。

必须遵守：

- 手机采用适合触控的布局和信息层级，不只是缩小桌面页面、字体或按钮。
- 精简首页展示，不删除学习功能、历史记录、收藏或云端数据。
- 字幕上方保留双语、跟读、挖空、听写词等必要入口；整理布局不等于取消功能。
- 上一句／下一句与上一条视频／下一条视频必须明确区分。
- 保持重点词颜色和下划线，逐词播放状态不能把重点词改成黑色。
- 复用现有原生前端及共享模块，不为此次改版更换框架、增加 UI 库或复制一套业务数据。
- 不默认修改数据库结构、VIP 权限、540P 生产配置、DeepSeek 教学内容逻辑。
- 用户已授权实施、提交和上线；按仓库规则发布。真机、生产媒体验证的限制在发布记录中单独列明。

## 4. 手机首页设计

### 4.1 信息顺序

```text
视频学习
搜索视频、主题或博主
继续学习：小封面＋标题＋继续按钮（仅有真实未完成记录时）
全部／日常生活／旅行／更多分类
一个视频列表：真实封面＋两行以内标题＋时长／中文难度
底部：视频／发现／生词／我的
```

- 无学习记录直接展示视频，不用“开始第一个视频”等大卡填满首屏。
- 移除手机首页自动轮播展示，原视频仍在列表、合集仍在发现，不能删除内容记录。
- 首页不铺完整目标设置、日历、长简介、励志语、多组推荐。它们按用途移位；无用途装饰可不展示。
- 视频列表窄屏单列，宽屏按卡片可读宽度调整。图片保比例，标题最多两行，分类来自统一真实数据。
- 搜索保留，隐藏手机上的 Ctrl K 提示。分类过多放更多面板，不堆九个大图标。
- 数据加载、请求失败、无匹配结果、资料库确实无视频分别反馈。错误提供重试，不能展示虚假空态。
- 四入口为推荐方案：发现含合集与博主，我的包含学习数据、目标、观看历史、收藏、会员。保留旧路由可达性；进入播放器不叠加全站底栏。

### 4.2 数据规则

- 手机和桌面共用目录、权限和学习记录，仅布局不同。
- 主列表所有条目遵守同一筛选；按视频 ID 去重，不按标题去重。
- 分页必须与服务端筛选一致，不把当前页搜索当全站搜索。先复用已有分页接口；若目录接口没有分页，再单独评估最小扩展。
- 首页继续学习按当前账号真实记录计算，账号切换清理旧账号缓存。
- 返回首页恢复搜索、分类、排序及列表位置；恢复滚动须等待列表布局就绪。

```js
// 契约示例：接入现有目录查询层，不另建 Mock 数据。
let latestRequest = 0;
async function reloadHome(filters) {
  const requestId = ++latestRequest;
  setHomeStatus('loading');
  try {
    const result = await catalogAdapter.listPublished(filters);
    if (requestId !== latestRequest) return;
    const items = [...new Map(
      result.items.map(video => [String(video.id), video])
    ).values()];
    renderHomeList(items, result.nextCursor);
    setHomeStatus(items.length ? 'ready' : 'empty');
  } catch (error) {
    if (requestId !== latestRequest) return;
    setHomeStatus('error');
  }
}
```

说明：上述 adapter、render 函数是待映射接口名。实际项目为原生 JS，不需为了示例引入 TypeScript 或框架。离开路由时同时取消请求或使序号失效。删除首页 DOM 区域前，必须同步调整访问这些区域的渲染、事件和轮播计时器，不能只删 HTML 留下空节点调用。

## 5. 手机播放页设计

### 5.1 分区及固定方式

```text
返回／视频标题
视频画面（真实封面；播放中按媒体比例）
学习工具：双语／跟读／挖空／听写词
字幕区：唯一的主要垂直滚动区域
句子控制：上一句／播放暂停／下一句
视频控制：上一条视频／第2/8条·目录／下一条视频
底部安全区
```

“固定”是用户滚字幕时操作栏始终可见，优先用满视口 Grid 的非滚动行实现，不是到处添加 position:fixed。手机浏览器工具栏、刘海、安全区、横屏和软键盘均需验证。

低高度横屏允许视频与字幕并排，保持按钮可达，不把字幕挤成几像素。词卡或听写输入弹层有独立滚动及关闭按钮，键盘出现时不能遮住输入和提交。

### 5.2 字幕与逐词效果

- 句子文本只保留一个可访问语义层，避免两个文本图层字距不一致导致字母错位。
- 逐词时间数据与重点词/短语范围分开保存：前者控制播放状态，后者控制教学标记。
- 正常英文优先按词换行；超长单词、链接允许应急换行，不逐字强制拆分全部单词。
- 挖空按现有教学单位生成，不能仅按字符数拼一排无界限下划线。核对缩略词、连字符词、标点、多个词的短语。
- 不使用原始句子 HTML 拼接插入；优先 textContent/安全 DOM，保留已有转义规则。
- 时间匹配使用 start <= currentTime < end。句间间隙可保留上一句；间隙中不得误判为正在说上一句。
- 尚未获取字幕显示加载状态；确实无字幕才显示真实空态；已有字幕的静默间隙不显示“暂无字幕”等干扰文字。
- 点击重点词打开词卡，不冒泡触发句子 seek；触控滑动结束不得产生误点词。

### 5.3 字幕跟随

状态区分 follow（自动跟随）与 browse（用户手动浏览）。仅可信的手动滚动手势进入 browse，程序滚动不能将自己误判为用户操作。browse 显示轻量“回到当前句”，点击后恢复跟随，不用计时器强行把人拖回。

```js
// 只滚字幕容器，不用可能连带滚动整页的无条件 scrollIntoView。
function keepSentenceVisible(container, row, follow, reducedMotion) {
  if (!follow || !row) return;
  const area = container.getBoundingClientRect();
  const item = row.getBoundingClientRect();
  const inset = 16;
  if (item.top >= area.top + inset && item.bottom <= area.bottom - inset) return;
  const delta = item.height > area.height - inset * 2
    ? item.top - area.top - inset
    : item.top - area.top - (area.height - item.height) / 2;
  container.scrollTo({
    top: container.scrollTop + delta,
    behavior: reducedMotion ? 'auto' : 'smooth'
  });
}
```

切句、seek、字幕渲染完成后再更新位置，不每个播放帧重建整个字幕 DOM 或反复平滑滚动。

### 5.4 模式、进度与音量

- “正常播放”连续播放当前视频；“循环跟读”循环当前句，学习者可跟着读，不强制打开麦克风。
- 如保留“一句一停”，它必须是独立明确选项。停顿后播放应重播当前句，只有下一句按钮切换句子。
- 双语、挖空、听写词保留既有语义；执行前列出现有开关组合，禁止为了排版把它们简化成无功能的按钮。
- 进度条只在明确拖动手柄/专用进度面板并完成提交时 seek。纵向滑动取消 seek，支持键盘调整；显示预览时间但不在每次指针移动都重载媒体。
- 音量支持百分比滑杆及静音恢复。iOS 等可能由系统管理媒体音量，不能假称网页滑杆能改变系统音量；受限时使用系统音量说明和可用静音能力。
- 维持单档 540P，不新增假“自动画质”或画质切换按钮。

## 6. 连续播放与返回上一条视频

### 6.1 队列来源及导航

- 从合集进入：使用合集的稳定排序；从分类或搜索进入：使用当前筛选的稳定顺序；直接链接进入：优先恢复该账号有效的队列，否则单条播放，不偷偷换成随机推荐。
- 队列以 videoId 定位，不能用 DOM 顺序或标题；如分页未加载完，应按同一排序获取后续数据，而不是只连播第一页。
- 底部“上一条视频／第 N/M 条·目录／下一条视频”与句子导航分开；总数未知时不能伪造 M。
- 首条上一条不可用；末条停止并显示已播完，不默认无限循环。
- 用户手动点上一条时，从上一视频 0 秒开始，保留该视频原学习记录和完成状态。播放位置与历史累计学习量不能混用一个字段。
- 返回视频列表恢复来源与滚动位置；上一条视频不是浏览器 history.back。

### 6.2 状态和事件优先级

```ts
// 规格类型，不要求项目引入 TypeScript。
type PlaybackState = {
  videoId: string;
  mode: 'normal' | 'sentence-loop' | 'sentence-pause' | 'dictation';
  sentenceId: string | null;
  autoplayNext: boolean;
  transition: 'idle' | 'loading' | 'awaiting-user' | 'error';
  sessionEpoch: number;
};
```

优先级：显式用户操作 > 练习模式句子边界 > 正常模式视频结束连播。

1. 循环跟读到句尾：回当前句开头继续播放，不能推进视频队列。
2. 一句一停到句尾：暂停，下一次播放重播当前句。
3. 听写未结束：不自动跳下一视频；显式切换前保存输入或提示未完成练习。
4. 正常模式媒体 ended：仅连播开启且有下一条时进入下一条。若使用倒计时，必须可取消；离开、暂停、切模式或手动切视频都取消旧倒计时。
5. 连播被浏览器策略拒绝：显示真实封面和“点击播放”，不能无限重试 play()。
6. 切换失败保留目标说明和重试入口，禁止悄悄跳过视频或无限循环换片。

### 6.3 切换事务规则

```js
// 生命周期契约示意；通过现有播放器适配，不另造第二个播放器。
async function switchVideo(targetId, reason) {
  const epoch = ++state.sessionEpoch;
  cancelPendingCountdown();
  cancelOldMediaRequests();
  enqueueStudyFlushForCurrentVideo(); // 有界异步，沿用幂等 outbox。
  stopAndDetachOldMedia();
  closeOldWordCard();
  setTransition('loading');
  try {
    const session = await loadAuthorizedVideoSession(targetId);
    if (epoch !== state.sessionEpoch) return;
    mountVideoSession(session, { startAt: 0 });
    resetSentenceCursorFor(targetId);
    try {
      await media.play();
      if (epoch === state.sessionEpoch) setTransition('idle');
    } catch (error) {
      if (epoch !== state.sessionEpoch) return;
      setTransition(error.name === 'NotAllowedError' ? 'awaiting-user' : 'error');
    }
  } catch (error) {
    if (epoch === state.sessionEpoch) showVideoLoadError(targetId, error);
  }
}
```

真实实现须保证切换幂等、事件解绑、旧异步回调失效、字幕和词卡属于同一 videoId。快速连续点击不出现旧视频声音叠加或新视频套旧字幕。服务端授权仍逐视频检查，前端队列不授予任何权限。

## 7. 加载速度与既有 540P 路线的保护

本轮不因 UI 改版再次转码，不回到 720P/480P 多档，不删除旧云对象。历史 540P 参数为兼容约束，实际发布媒体以当前服务端清单为准。

用户报告过 Wi-Fi 快但视频、图片慢，以及刷新时登录闪框。这些不能仅归因于分辨率。验证时分开记录：页面静态资源、会话恢复、播放授权、清单、首个媒体分片、后续缓冲、封面/头像读取的耗时和失败状态。

- 会话初始化使用 loading/authenticated/anonymous/error，尚未完成判断不渲染登录页再闪回。
- 已有真实封面从进入详情即显示，播放开始或缓冲有状态反馈，不再使用无关默认花朵图。
- 封面首屏优先，列表下方图片按需加载，设置尺寸防布局跳动。
- 首页移除轮播时也清理计时器，不只用 CSS 隐藏。
- 不默认下载整条下一视频；弱网及节省流量时不做媒体预取。确需预取须有上限、取消及授权隔离。
- 私有媒体、头像与播放票据不得为“加速”公开，也不得混用不同账号缓存。网络失败不能提示成 VIP 无效。

## 9. 必测清单与发布门槛

### 9.1 测试矩阵

- 视口：320/360/390/430/768/1024 及桌面；低高度横屏；字体放大、安全区、浏览器工具栏展开/收起。
- 浏览器：Android Chrome、iPhone Safari、常用微信内置浏览器尽可能真机验证；无法实测逐项写明，不能用桌面模拟代替真机结论。
- 首页：0/2/多页视频、无历史/有历史、长标题、缺封面、分类无结果、请求失败、快速切类、返回恢复、账号切换。
- 字幕：长词、短语、标点、无字幕、加载中、静默间隙、句尾、最后一句、seek、手动滚动和恢复跟随。
- 模式：正常/循环跟读/一句一停/听写切换；重点词不变色；必要入口不丢；弹层打开后仍能滚动与关闭。
- 队列：A→B→返回A→B；首末条；仅一条；分页边界；关闭连播；快速切片；自动播放被阻止；目标下架、无权限或加载失败。
- 数据：正常播放产生真实观看时长；暂停/缓冲不累计；seek 跳过不算观看；循环实际听的时间按既有统计规则处理；重试同步不重复记账；跨设备可恢复。
- 安全：匿名/过期会员不因新入口获得播放权；有效会员沿既有授权播放；不泄露私有地址或混用账号缓存。
- 媒体：现有两条 540P 可播放、字幕同步；UI 改版不改变转码、媒体路径或存储对象。
