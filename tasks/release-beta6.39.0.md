## 范围与规格

本轮落实用户在手机学习方案基础上追加确认的播放器要求，沿用 tasks/mobile-learning-iteration-20260915/plan.md 的连播与学习功能约束。主要归属 M04，必要集成 M06 生词公开契约；不变更会员准入、管理端业务、上传处理、540P 媒体或数据库结构。无需 Supabase 迁移，不删除任何 R2 对象。

- 字幕按单词独立高亮，重点色和下划线保留；短语跨行时不绘制整个短语的定位边框，点词和填空仍保留完整短语身份。估算、错位或失效的逐词时间不伪装为准确对齐。
- 手机播放器采用顶部导航、实际比例视频、字幕/练习工具、独立滚动字幕、持续可见底部控制五区布局；移除字幕区辅助描述，默认英文17px、中文13px，字号仍可调整。
- 字幕语言、逐句/循环/填空保留；更多菜单保留速度、音量、设置和分析；句子复制收藏手机折叠、桌面可见。
- 底部保留进度及句子控制，目录可切上一条/下一条视频和连续播放；重点词按明确教学词去重计数，生词按当前账号云端确认数据计数，可筛选当前视频，未加载显示“—”。
- 生词面板打开其他视频的词时保留原释义和原句；保存失败不假装成功，不串用其他账号计数。
