## 三、与上一阶段一起修复的通路

1. 图片：合集引用当前有效视频；320/640/960 WebP 按显示尺寸加载。401 仅续期一次，网络/503 有限重试，403/404 不无限循环。VIP 校验保留。
2. 难度：DeepSeek 候选 → 严格字段与字幕证据校验 → 审核 → 发布目录 → 学员展示及筛选。后台与学员共用标签枚举，内部 CEFR 字段不删除。
3. 教学：只选择真实俚语、四级及以上有学习价值的短语和单词；允许一句零重点，不凑数量，不把基础自由组合当固定短语。不伪造官方考试归属。
4. 短语：一个语义父元素包住全部单词和中间空格，父元素画连续下划线；内部单词仅负责时间高亮。允许换行但禁止跨行绝对定位包围框。
5. UI：沿用已经确认的紧凑骨架；更多与偏好统一深浅主题；播放按钮、字幕、目录、上一条/下一条等业务入口保持一一对应。

- 词卡/生词本/复习没有合成发音或口音按钮；原句与视频原声正常。
- 手机首页和发现页双列，更多/偏好可滚动、可返回，两主题均无横向溢出。
- 短语空格处下划线连续、跨行无大框；逐词进度不改变重点词颜色。
- 图片最多有限重试；切换账号不会用旧票据；旧合集指向实际成员当前资源。
- 学员难度显示与后台审核字段一致；证据不足不编造标签。
- DeepSeek 对基础片段不凑数，人工锁定不被覆盖；新旧内容状态可区分。
- 不改变 VIP、540P、邀请码、学习进度、原声与连续播放规则。
