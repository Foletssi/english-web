# 生词本、词卡、视频目录与重点词界面迭代

基线：e473bc7（beta6.45.0）。用户要求将 image2.5 设计落实到四个现有界面，保留雾蓝深浅主题、小屏紧凑布局、重点词颜色及全部既有功能。不得重做两个旧视频的数据。

## 视觉来源

实际使用 gpt-image-2.5 生成四张深浅双主题参考图。本地文件在 output/imagegen/study-surfaces-20260916/：notebook.png、word-card.png、directory.png、highlights.png。参考图不作为网站背景或控件位图发布，实际界面使用 HTML、CSS 和 SVG，以适配不同宽度和真实数据。

## 实施约束

- 生词本：四项真实统计合并为紧凑横条；搜索、筛选、列表/卡片切换、复习、掌握、删除、导出保持。词条展示释义与原句；手机原句至多两行，复习仍能查看原文。
- 词卡：保留真实发音及状态、核心释义、语境说明、原句、复制和收藏。使用统一雾蓝表面、细线图标及例句区域。头部与底部固定，中部独立滚动；没有数据的字段保持隐藏。
- 视频目录：真实封面、标题、难度、时长、当前视频状态；长标题最多两行。复用已有封面压缩与故障恢复链路。保持原队列筛选、去重、前后视频和切换确认逻辑。
- 重点词：整词/短语显示，沿用实际字幕的重点色，直接显示已有核心释义；点击进入现有词卡。跨视频生词保留原视频释义与来源，不套用当前视频语境。
- 不添加假统计、未接通按钮、额外导航、词语类别或补造释义；不更改教学筛选及视频内容。

## 尺寸与验收

- 弹层最大 480px，手机两侧 8px；最大高度受动态视口和安全区约束。
- 目录缩略图 80×45px，保持 16:9；标题 13px、元信息 11px。
- 重点词标题 17px，释义 13px；词卡标题 22px、核心释义 17px。
- 生词本标题 26px，词条 18px，操作图标 18px/触控区域 40px；词卡关闭/发音触控区 44px。
- 验证 320、390、768、1024、1440px 的布局以及深浅主题，无水平溢出；长词条、弹层滚动、关闭、收藏、复习、删除、跨视频来源及队列操作须通过现有浏览器测试。
- 本次无数据库迁移，无旧视频更新，无 R2 清理。
