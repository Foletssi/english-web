# 第3套雾蓝播放器：紧凑尺寸与组件契约

日期：2026-09-16。状态：已接入 beta6.42.0 发布候选。实际代码、组件映射与验证边界见 [IMPLEMENTATION.md](./IMPLEMENTATION.md)，上线结果见 `tasks/release-beta6.42.0.md`。

本文以下保留原设计原型的测量记录，不能替代实际应用参数。接入时的差异（底栏列宽、图标统一尺寸、横屏与视频限高等）以 IMPLEMENTATION.md 为准；第7节的32组是独立原型测试，并非应用测试。

## 1. 本次确认内容

- 采用用户选择的第3套雾蓝双色外观，配色对齐此前主页第3套“雾蓝·视频书架”。这里的“主控第3套”按该主页设计理解，不是后台管理界面。
- 保持第4版“视频与歌词”的区域顺序、全宽视频、字幕独立滚动、常驻底栏。盲听使用相同外壳，仅改变字幕显示状态。
- 只减少底栏留白、行距和视觉按钮尺寸，不纵向压扁组件，不删减功能，不把省下的空间重新用于装饰卡片。
- 重点词仍有彩色和短语下划线；播放逐词经过时不改变重点词颜色。
- 图像是外观参考；所有准确尺寸以本目录 player.css 和本文为准。生成图不能作为逐像素实施依据。

## 3. 新的尺寸基准：112px + 实际底部安全区

全部单位是CSS px，不是截图像素或手机物理像素。

```
屏幕顶部
  安全区T + 标题44
  视频 W × 9/16，高度由宽度决定
  练习模式44
  字幕滚动区：剩余空间
  底部播放栏：进度24 + 控制44 + 学习工具44
  系统底部安全区B
屏幕底部
```

令W为可用网页宽度，H为100dvh可用网页高度，T/B为实际env安全区：

```js
const headerHeight = T + 44;
const videoHeight = W * 9 / 16;
const modeHeight = 44;
const dockHeight = 112 + B;
const dockY = H - dockHeight;
const transcriptY = T + 44 + videoHeight + 44;
const transcriptHeight = dockY - transcriptY;
```

这是说明公式，布局由CSS Grid计算，不需要每帧用JS设置高度。H不含浏览器已占用的地址栏，不可以再手动减一次地址栏高度。普通浏览器安全区可能为0，独立应用模式可能不为0；不得固定给所有手机加34px，也不得自行画系统状态栏和Home横条。

### 新版实测示例：390×844，T=0，B=34

| 组件 | x | y | 宽 | 高 |
|---|---:|---:|---:|---:|
| 标题栏 | 0 | 0 | 390 | 44 |
| 视频 | 0 | 44 | 390 | 219.375 |
| 练习模式行 | 0 | 263.375 | 390 | 44 |
| 字幕滚动区 | 0 | 307.375 | 390 | 390.625 |
| 底部进度行 | 8 | 698 | 374 | 24 |
| 播放控制行 | 8 | 722 | 374 | 44 |
| 学习工具行 | 8 | 766 | 374 | 44 |
| 系统安全区 | 0 | 810 | 390 | 34 |

B=0时底栏从y=732开始，字幕增高34px。底栏不盖在字幕上，两者边界由同一Grid布局计算。本文所谓“固定底栏”指页面外壳固定、只有字幕滚动，不需要再给竖屏底栏叠加position:fixed。

## 4. 每个组件的规格、定位与防变形约束

|---|---|---|---|

| 标题 | 14px/600 | 中间剩余宽 | 单行省略，不推挤按钮 |
| 视频 | 框16:9，内容保持原比例 | 宽度100% | x=0，标题下方；无圆角无左右卡片边距 |
| 全屏图标 | 18×18 | 44×44 | 视频right:4px;bottom:0 |
| 视频时间 | 11px | 非按钮 | 视频left:12px;bottom:14px |
| 四个模式 | 11px文字；需要图标时14×14 | 每格(W−16)/4 ×44 | x=8+i×(W−16)/4，i=0..3 |
| 英文字幕 | 17px，行高1.6 | 宽W−32 | 320宽时16px，左右各12 |
| 中文字幕 | 13px，行高1.6 | margin-top:5 | 不加额外描述段落 |
| 每句时间 | 11px | 元信息行左侧剩余空间 | 句子文字下方margin-top:4 |
| 每句发音、收藏 | 18×18 | 各44×44 | 元信息行右侧两格 |
| 盲听提示与显示字幕 | 13px | 提示行44，显示按钮至少88×44 | 字幕区域顶部，不额外增加页面分区 |

| 进度输入 | 视觉轨道建议3px | 输入高度24 | 底栏首行，不扩大覆盖字幕的透明区域 |
| 倍速、盲听、上句、下句、更多 | 18×18图标，10px说明 | 每格(W−16)/6 ×44 | x=8+i×(W−16)/6，i=0..5 |

进度条的浏览器默认绘制外观可能不同，原型先验证24px输入盒；落地时分别定义WebKit/Mozilla轨道和滑块，不改24px点击盒。滑块可10×10px正圆，不能撑大行高。

### 禁止用整体缩放解决拥挤

```css
/* 正确：视觉和点击盒分开，图标和圆钮不参与挤压 */
.player svg {
  width:18px; height:18px; flex:none;
  stroke-width:1.7;
}
.player .disc {
  width:32px; height:32px;
  min-width:32px; min-height:32px;
  flex:none; aspect-ratio:1; border-radius:50%;
}
.player .video-frame {width:100%; aspect-ratio:16/9; margin:0}
.player video {width:100%; height:100%; object-fit:contain}
/* 不使用 scaleY、非等比transform、zoom或object-fit:fill。 */
```

“视频铺满手机”指视频容器左右铺满，不是将横向视频拉成竖向。非16:9素材以contain保全画面，必要的黑边比拉伸人脸或裁掉字幕更合理。横屏低高度时独立降级：视频限高180且contain，页面可滚动，底栏仍固定，不硬塞成负数字幕高度。横屏方案需要另行真机验收，本次不宣称已覆盖所有设备。

## 5. 主页与播放器共用颜色

主页第3套目前是生成图，不存在可直接读取的精确设计色变量。下列为此次从视觉方向制定的共享色值，不冒称来自已有主页源码。将来主页和播放器应引用同一主题源，不能各自复制后改出两套蓝色。

| 语义 | 浅色 | 深色 |
|---|---|---|
| 页面背景 | #F7FAFE | #111C2A |
| 表面/底栏 | #FFFFFF | #172536 |
| 正文 | #17263D | #E8EFF8 |
| 次要文字 | #536983 | #A3B5CC |
| 分隔线 | #DCE5EF | #2D4057 |
| 品牌蓝/播放钮 | #4C82B8 | #85B7E7 |
| 可点击文字 | #346DA5 | #85B7E7 |
| 选中背景 | #E8F1FA | #243D57 |
| 重点词示范色 | #A85400 | #F3B967 |
| 当前单词底色 | #FAECD9 | #443522 |

重点词属于教学语义色，不跟按钮一起刷成蓝色。若生产系统已有用户确认的多类重点词颜色，应保留原语义变量映射，不能用本原型的单一示范色覆盖所有类别。同一主题下，播放、暂停、hover、当前词经过，重点词前景色都不改变。切换深浅主题允许用对应的可读配对色。

```html
<span class="phrase">
  <span class="word" data-active="true">get</span>
  <span class="word">my</span>
  <span class="word">bearings</span>
</span>
```

短语使用父级text-decoration自然下划线；逐词状态只改变子级背景。禁止给跨行短语用绝对定位矩形边框，禁止white-space:nowrap造成溢出；换行后分别在每行文本下划线，不出现跨行包围框。

## 6. 文件与接入边界

- player.css：完整可运行的尺寸与主题CSS；仅作用于.player，未来接入也需限定手机播放器路由，不能污染后台和桌面播放器。
- index.html：尺寸验证原型；只有主题/盲听切换可交互，其他为组件占位。图标字符用于尺寸占位，不是最终图标资源；落地用统一SVG viewBox="0 0 24 24"和preserveAspectRatio="xMidYMid meet"替换，保持上述盒尺寸。
- 本文：尺寸、证据、接入要求。生成图仅作美化方向，不是尺寸测试截图。

后续接入保留现有业务函数，只适配对应组件；以下是接口契约示例，函数名需匹配真实模块，不能直接假装已经存在：

```ts
type PracticeMode = 'continuous' | 'sentencePause' | 'sentenceLoop' | 'cloze';
interface PlayerActions {
  setPracticeMode(mode: PracticeMode): void;
  togglePlayback(): void;
  setBlindListening(enabled: boolean): void;
  previousSentence(): void;
  nextSentence(): void;
  setPlaybackRate(rate: number): void;
  seek(seconds: number): void;
  openMore(): void; // 字幕设置、其余不常用设置
  openKeywords(): void;
  openVocabulary(): void;
  markLearned(): Promise<void>;
  openVideoDirectory(): void; // 包含上一条/下一条视频，不能与上句/下句混用
}
```

计数28/3仅为原型示例。真实重点词数来自当前视频已发布教学数据去重结果；生词本数来自当前账号已保存数据，未加载时不伪造数字。禁止此次样式改动触发AI重处理或改会员权限。

进度输入落地时：拖动中仅预览，确认后seek一次；区分水平拖动与竖向滑动，竖向意图应取消seek。这需要实际触屏事件测试，不是CSS能单独保证的。
