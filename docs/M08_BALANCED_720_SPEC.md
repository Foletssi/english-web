# M08 均衡720P与隐藏自动处理

基线：67aa02d；需求来源：2026-09-12 用户确认。

## 验收

1. 所有新上传共用 media_tools.ladder：单档720p、CRF25、maxrate1000k、medium、最高30fps、AAC96k、4秒HLS；小于720P的原片不放大。
2. 现有视频1788926081632与1789024924932重新转码；仅切换播放媒体，不重新跑AI，不改变字幕、词卡、合集、发布状态或学习记录。
3. 新媒体独立目录上传，逐项回执校验后原子切换。失败时旧视频保持可用，禁止物理删除R2对象。保留旧任务用于回滚。
4. Windows登录后隐藏启动；运行中不弹CMD/FFmpeg窗口；进程停止后每分钟补启动；重复启动不产生第二个处理进程。
5. 电脑关机、未登录或休眠时不能提供本地算力，云端队列保存任务，恢复后继续领取；不能宣传网页能够远程唤醒关机电脑。

## 验证

- media_tools单测：参数、低分辨率不放大、旧配置缓存失效、真实FFmpeg转码。
- 自动启动契约与PowerShell解析、实际任务注册、进程窗口句柄、云端heartbeat。
- 媒体维护接口：仅service_role、旧任务一致性、回收站检查、回执完整性、视频字段局部更新。
- 全量npm run test:all；Supabase CLI migration/lint；线上播放清单与首中尾分片HTTPS校验。
